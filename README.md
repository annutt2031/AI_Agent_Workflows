# AI Agent Workflows with n8n

## Описание проекта

Проект представляет собой набор AI-агентов и автоматизированных workflow, созданных с использованием **n8n** и больших языковых моделей.

Цель проекта — изучение возможностей автоматизации процессов с использованием AI: создание интеллектуальных помощников, обработка пользовательских запросов, генерация контента и анализ информации.

В рамках проекта были реализованы несколько сценариев:

- AI-помощник по выбору карьерного направления;
- AI-ассистент для обучения;
- анализ требований рынка вакансий;
- автоматическая генерация IT-дайджестов.

Workflow построены на основе событийной архитектуры: пользователь отправляет запрос → n8n запускает сценарий → AI Agent обрабатывает информацию → пользователь получает результат.

---

# Используемые технологии

## Основные инструменты

- **n8n** — платформа автоматизации процессов и построения workflow;
- **AI Agent** — создание интеллектуальных агентов;
- **LLM (Large Language Models)** — генерация и анализ текстовой информации;
- **Telegram Bot API** — взаимодействие с пользователем через чат-бота;
- **JSON workflow configuration** — хранение и перенос сценариев автоматизации.

# Архитектура проекта

Общая схема работы:

```
Пользователь
     |
     ↓
Telegram Bot / Chat Interface
     |
     ↓
n8n Workflow
     |
     ↓
AI Agent
     |
     ↓
LLM Model
     |
     ↓

```

Каждый workflow отвечает за отдельную бизнес-задачу и может быть расширен дополнительными источниками данных или интеграциями.

# Реализованные workflow

## 1. AI Career Consultant Bot

Файл:

```
workflows/AI_Career_Consultant_Bot.json
```

### Назначение

AI-помощник для первичного карьерного консультирования.

Бот проводит диалог с пользователем, собирает информацию о:

- текущих навыках;
- интересующих направлениях;
- целях развития;
- предпочтительном формате работы.

После анализа ответов формирует рекомендации по дальнейшему развитию.

### Реализованные возможности:

- проведение структурированного интервью;
- анализ пользовательского опыта;
- формирование персональных рекомендаций;
- генерация карьерного направления.

Пример результата:
пользователь описывает свой опыт и интересы → AI анализирует информацию → предлагает подходящие направления развития.

# 2. AI Learning Assistant

Файл:

```
workflows/AI_Learning_Assistant.json
```

### Назначение

AI-ассистент для построения индивидуального плана обучения.

Пользователь указывает:

- тему обучения;
- текущий уровень знаний;
- желаемое направление.

После этого система формирует учебный план и предоставляет объяснение материала.

### Реализованные возможности:

- генерация программы обучения;
- объяснение технических тем;
- адаптация сложности под пользователя;
- последовательное прохождение материала.

Пример:

Пользователь:
"Machine Learning, начинающий уровень"

AI:
- определяет необходимые темы;
- формирует план обучения;
- объясняет основные понятия.

# Ограничения запуска

На текущий момент оригинальные workflow не могут быть полностью запущены в рабочем режиме.

Причины:

- использованные API-токены были предоставлены только на период выполнения проекта;
- часть внешних сервисов и интеграций больше недоступна;
- Telegram-интеграция ограничена текущими условиями использования.

Поэтому данный репозиторий содержит:

- сохранённые workflow;
- структуру автоматизации;
- описание архитектуры;
- результаты работы системы.

Основная цель публикации — демонстрация опыта проектирования AI-агентов и автоматизации процессов с использованием n8n.
