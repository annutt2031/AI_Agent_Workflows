# AI-Agent Workflows

Коллекция автоматизированных AI workflow, созданных в n8n.

Проекты демонстрируют использование:
- AI Agent;
- LLM-моделей;
- Telegram Bot API;
- внешних API;
- обработки данных;
- автоматизации рабочих процессов.

Основные направления:
- карьерный помощник;
- анализ рынка вакансий;
- генерация учебных материалов;
- автоматический новостной дайджест.
