# Architecture

Общий принцип работы workflow:

```
Источник события
(Telegram, Schedule Trigger, API)
        |
        ↓
n8n Workflow
        |
        ↓
Обработка данных и управление логикой
        |
        ↓
AI Agent + LLM Model
        |
        ↓
Формирование результата
        |
        ↓
Возврат пользователю или отправка результата

```

Основные компоненты:
- n8n — оркестрация процессов;
- LLM — генерация и анализ текста;
- Telegram API — взаимодействие с пользователем;
- внешние API — получение данных.
